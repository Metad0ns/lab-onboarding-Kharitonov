# Анализ ассемблерного кода (x86-64, AT&T)

## Разбор по строкам
- `movl $0, -4(%rbp)`: переменная по адресу -4(%rbp) = 0 (аккумулятор
  суммы, `total`).
- `movl $1, -8(%rbp)`: переменная по адресу -8(%rbp) = 1 (счетчик, `i`).
- `jmp .L2`: сразу переходим к проверке условия цикла.
- `.L3`: тело цикла.
  - `movl -8(%rbp), %eax`: eax = i.
  - `addl %eax, -4(%rbp)`: total += i.
  - `addl $1, -8(%rbp)`: i += 1.
- `.L2`: проверка условия.
  - `cmpl $10, -8(%rbp)`: сравнить i с 10.
  - `jle .L3`: если i <= 10, перейти к телу цикла (jump if less or equal).
- `movl -4(%rbp), %eax`: eax = total (результат функции).

## Эквивалентный код на Python
    def sum_to_ten():
        total = 0
        i = 1
        while i <= 10:
            total += i
            i += 1
        return total

## Результат
Функция суммирует числа от 1 до 10 включительно: 1 + 2 + ... + 10 = 55.
