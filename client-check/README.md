# Диагностика и аудит клиентского компьютера

Дважды щёлкните по `pc_info.bat` в Проводнике Windows. Храните `pc_audit.ps1` в той же папке. Скрипт выводит результаты в окно и сохраняет `pc_report.txt` рядом с собой. При повторном запуске отчёт перезаписывается.

## Офисный эталон

| Категория | Примеры | Зачем нужна |
| --- | --- | --- |
| Офисный пакет | Microsoft Office, LibreOffice, МойОфис | Редактирование документов и таблиц |
| Браузер | Chrome, Firefox, Яндекс Браузер, Edge | Доступ к корпоративным веб-сервисам |
| Чтение PDF | Acrobat, Foxit PDF Reader, SumatraPDF | Просмотр документов и заполнение форм |
| Архиватор | 7-Zip, WinRAR, WinZip | Работа с архивами и почтовыми вложениями |
| Антивирус | Microsoft Defender, Kaspersky, ESET, Dr.Web | Защита рабочего места |

Обнаруженный Microsoft Edge помечается как компонент Windows. Если антивирус не обнаружен в списке, отчёт предлагает проверить состояние Defender или наличие утверждённого средства защиты.

## ПО для дополнительной проверки

- Игры и игровые платформы: Steam, Epic Games, GOG, Origin, Ubisoft Connect, Battle.net, Riot, слова `game`, `games` и `gaming`.
- Торрент-клиенты и файлообмен: torrent, uTorrent, BitTorrent, qBittorrent, Vuze.
- Мессенджеры: Discord, Telegram, WhatsApp, Viber, Skype. Список сверяют с утверждёнными каналами связи.
- Развлечения и оформление: Wallpaper Engine, OBS, Soundpad. Эти приложения могут решать согласованные рабочие задачи.

Счётчик включает одну рекомендацию за каждую категорию базового ПО без совпадений и одну за каждую группу дополнительной проверки с совпадениями. Решение о дальнейших действиях принимает администратор.

## Проверка логики

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\pc_audit.ps1 -Mode Test
```

В исходном тестовом списке все пять категорий закрыты, включая архиватор 7-Zip, и рекомендаций нет. Во втором списке 7-Zip исключён, а Steam добавлен. Проверено, что появился совет установить архиватор, Steam попал в игровую группу, а счётчик показал две рекомендации. Тестовые названия используются только в режиме `Test`.

## Источники и ограничения

ОС, процессор, память и диск C опрашиваются через `Get-CimInstance`. Объёмы переводятся в гигабайты по степеням 1024. При сбое отдельного запроса соответствующее поле получает сообщение «данные получить не удалось».

Список программ строится по значениям `DisplayName` из раздела `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall` в 64- и 32-разрядных представлениях. На 64-разрядной Windows второе соответствует `WOW6432Node`. Названия сортируются, повторы убираются. Приложения, установленные только для пользователя, переносимые программы и компоненты без записи в этих разделах могут отсутствовать в списке.

Аудит ищет совпадения в названиях без учёта регистра. Возможны совпадения с одноимённым ПО и пропуски продуктов с другими названиями. По этому списку нельзя определить, используется ли программа, настроена ли она или включена ли антивирусная защита.
